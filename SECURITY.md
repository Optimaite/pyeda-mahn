# Security Policy

## Supported Versions

Security fixes are provided for the latest released minor version.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability.

Email `security@optimaite.eu` with:

- a short description of the issue,
- affected versions or commits,
- reproduction steps or a proof of concept when possible,
- whether the issue is already public.

Optimaite will acknowledge receipt, triage the report, and coordinate a fix and disclosure timeline.

## Scope

`pyeda-mahn` is a pure encoder/parser library. It does not perform transport, authentication, beA/EGVP delivery, signing, persistence, or payment handling. Security reports are still welcome for parser crashes, malformed-input denial of service, unsafe packaging, dependency problems, or output inconsistencies that could affect legal filing integrity.
