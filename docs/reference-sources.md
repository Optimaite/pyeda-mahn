# Reference Sources

`pyeda-mahn` implements the public EDA-Mahn fixed-width record format from the German automated court dunning process.

The public GitHub repository intentionally does **not** redistribute official PDF or ZIP specification files. Please download them from the official sources and verify the hashes before using them for implementation or audit work.
